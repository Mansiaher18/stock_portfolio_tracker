Stock Portfolio Tracker

Project Description

Stock Portfolio Tracker is a Python-based application used to manage stock investments. It calculates total investment, current portfolio value, and profit or loss.

Features

- Add stock details
- Store stock data in a CSV file
- View all added stocks
- Calculate total investment
- Calculate current stock value
- Calculate profit or loss
- Save data permanently using CSV

Technologies Used

- Python
- CSV File Handling

How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python main.py

How to Use

1. Select option 1 to add a stock.
2. Enter the stock name, quantity, purchase price, and current price.
3. Select option 2 to view your portfolio.
4. Select option 3 to exit the application.

Project Files

- "main.py" – Main Python program.
- "stocks.csv" – Stores stock information automatically.

Calculation

- Total Investment = Quantity × Purchase Price
- Current Value = Quantity × Current Price
- Profit/Loss = Current Value − Total Investment

Note

Stock prices are entered manually. Live market prices are not supported.

Conclusion

This project helps users track stock investments and understand their profit or loss using Python and CSV file handling.
